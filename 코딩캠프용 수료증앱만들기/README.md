# 로보그램 코딩캠프 수료증 발급 웹앱 (Robogram Certificate App)

학교 및 코딩 교육기관의 단기 코딩캠프 수료생들을 위한 맞춤형 수료증 발급 및 출력 웹 애플리케이션입니다.

---

## 🌟 주요 기능

### 1. 학생 전용 기능 (스마트폰 & 노트북/PC 완벽 지원)
- **학교명, 학생 아이디, 비밀번호** 입력 후 간편 로그인
- **수료증 출력 가능 기간 자동 검증**:
  - 관리자가 설정한 기간 외 접속 시 친절한 안내 배너 표시 및 출력 차단
- **학생 본인 사진 등록/수정**:
  - 스마트폰 카메라 촬영 또는 파일 선택 시 3:4 규격으로 자동 최적화 및 수료증 우측 상단 실시간 반영
- **맞춤형 출력 및 다운로드**:
  - **[🖨️ A4 수료증 바로 인쇄]** (노트북/PC 최적화): 브라우저 기본 인쇄창 호출 및 A4 1페이지 규격 완벽 여백 없는 인쇄 / 'PDF로 저장' 지원
  - **[📥 고화질 수료증 다운로드]** (스마트폰 최적화): 갤러리/사진첩에 300DPI급 고해상도 PNG 이미지로 즉시 저장

### 2. 관리자 기능 (관리자 비밀번호: `robogram^^`)
- **교육기관(학교) 및 캠프 설정**:
  - 학교/교육기관명 등록
  - 수료증 수업과목 이름 설정
  - 교육 시작일, 교육 종료일, 총 교육시간(시간 단위) 입력
  - **수료증 출력 가능 기간 (시작 일시 ~ 종료 일시)** 분 단위 정밀 설정
- **학생 명단 엑셀(CSV) 일괄 업로드**:
  - 엑셀 양식 샘플 제공 (`sample_data/학생명단_업로드양식.csv`)
  - 드래그 앤 드롭 또는 파일 선택으로 수십~수백 명 학생 명단 원클릭 등록
- **실시간 모니터링**:
  - 학생별 사진 등록 여부, 수료증 발급 여부, 출력 횟수 확인

## 🚀 실행 및 배포 방법

### 1. 로컬에서 바로 실행하기 (가장 간단한 방법)
- 폴더 내 **`실행하기.bat`** 파일을 더블클릭하면 로컬 서버가 실행되고 웹 브라우저(`http://localhost:8080`)가 자동으로 열립니다.
- 또는 터미널에서:
  ```bash
  python python_backend/app.py
  ```

### 2. 클라우드 무료 배포 (비용 0원, 전 세계 어디서나 접속)
- **추천 백엔드**: **Supabase** (PostgreSQL 500MB + Storage 1GB 영구 무료)
  - `database/supabase_schema.sql`의 SQL 문을 Supabase SQL Editor에 복사하여 실행하면 즉시 테이블이 생성됩니다.
- **추천 웹 호스팅**: **GitHub Pages**, **Vercel**, **Netlify**, **Cloudflare Pages** 또는 **Hugging Face Spaces**
  - 본 폴더의 파일들(`index.html`, `css/`, `js/`, `assets/`)을 올리기만 하면 별도의 서버 비용 없이 평생 무료로 구동됩니다.
- **오프라인/로컬 자동 지원**:
  - 네트워크 연결이 원활하지 않은 학교 컴퓨터실에서도 브라우저 로컬 저장소를 활용하여 100% 정상 작동합니다.

## 📂 폴더 구조
```text
├── index.html                 # 메인 웹앱 (학생 화면 + 관리자 화면)
├── 실행하기.bat               # 윈도우 원클릭 실행 파일
├── css/
│   └── style.css              # 반응형 UI 및 A4 인쇄(@media print) 스타일시트
├── js/
│   ├── app.js                 # 학생 로그인, 사진 업로드, 발급 기간 검증 로직
│   ├── admin.js               # 관리자 설정, 엑셀 일괄 업로드 로직
│   ├── certificate.js         # 수료증 렌더링, A4 인쇄, 고화질 캔버스 엔진
│   └── supabase_config.js     # Supabase 연동 및 로컬 DB 하이브리드 어댑터
├── assets/
│   ├── robogram_logo.png      # (주)로보그램 공식 로고
│   └── seal.png               # (주)로보그램 공식 직인 도장
├── database/
│   └── supabase_schema.sql    # Supabase 테이블 및 RLS 보안 스키마
├── sample_data/
│   └── 학생명단_업로드양식.csv    # 관리자용 엑셀 업로드 샘플 파일
└── python_backend/
    └── app.py                 # 파이썬 로컬 서버
```
